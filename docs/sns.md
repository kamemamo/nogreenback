## Facebook・note など向け・長め

【OBS なしで、PC の画面に自分を重ねて授業できるようになりました】

グリーンバックなしで Web カメラの映像から人物だけを切り抜く Mac アプリ「NoGreenBack」を、1.5 に更新しました。

これまでは、切り抜いた自分を Syphon で OBS に送って、スライドと重ねていました。今回の更新で、このアプリだけで授業の画面ができあがるようになりました。

・USB キャプチャーで取り込んだ PC の画面（Windows でも）を背景にして、切り抜いた自分を右下などの隅に小さく重ねます
・合成した映像を、プロジェクターや液晶タブレットに全画面で出せます
・液晶タブレットのペンで、画面にそのまま書き込めます
・その画面を録画できます。録画中にアプリが落ちても消えない「Hybrid MP4」方式で、止めると普通の MP4 になります
・録画に使うマイクを選べて、音量のメーターも付けました
・Stream Deck から、録画や全画面表示などをボタンひとつで操作できます

もちろん、今までどおり背景を透明にして Syphon で OBS などへ送ることもできます。

Apple Silicon の Mac（macOS 12 以降）で動きます。

### Facebook・note など向け・長め

【グリーンバックなしで自分だけを切り抜くアプリを作りました】

オンライン授業や配信で、スライドの上に自分の姿を重ねたい。でも、グリーンバックを用意して照明を整えるのは大変です。

そこで、普通の Web カメラの映像から人物だけをリアルタイムで切り抜く Mac アプリ「NoGreenBack」を作りました。

・Apple の人物認識（Vision）で、背景を自動で透明にします
・Syphon で送るので、OBS、Resolume、MadMapper などに重ねるだけで使えます
・輪郭のちらつきを抑える機能と、手を顔の前に出しても体が消えにくくする機能を付けました
・Apple Silicon の Mac（macOS 12 以降）で動きます

これで、Millumin を使わなくても、OBS だけで自分をスライドに重ねた授業ができます。

OBS では、Syphon クライアントのプロパティで「透過を許可」にチェックを入れるのがポイントです。

#OBS #Syphon #Mac #オンライン授業 #配信
